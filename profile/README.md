# Vector Graphics Lab

Public face of the [VectorGraphicsLab](https://github.com/VectorGraphicsLab) organization.

We work on **vector graphics + ML**: generative SVG, style transfer in the vector domain, and web tooling around these models.

## Public repositories

Canonical code belongs in this organization (mirrored to our GitLab group). Links below will switch to org URLs as transfers finish; some projects still live under personal accounts.

| Project | Description | Repository |
|---------|-------------|------------|
| **CoverGAN** | Album covers as SVG from audio and emotions | [IzhanVarsky/CoverGAN](https://github.com/IzhanVarsky/CoverGAN) (train) · [ML-VG-CoverGAN-service-backend](https://github.com/IzhanVarsky/ML-VG-CoverGAN-service-backend) (serve) |
| **VectorNST** | Neural style transfer for vector graphics | [IzhanVarsky/VectorNST](https://github.com/IzhanVarsky/VectorNST) |
| **VectorWeaver** | Generative SVG (class-conditional) | [IzhanVarsky/VectorWeaverClassConditional](https://github.com/IzhanVarsky/VectorWeaverClassConditional) |
| **ML-VG frontend** | Web UI for the vector-ML demos | [IzhanVarsky/ML-VG-service-frontend](https://github.com/IzhanVarsky/ML-VG-service-frontend) |
| **SVG object extraction** | Raster/open-vocab → SVG leaf selection pipeline | [IzhanVarsky/svg-object-extractor](https://github.com/IzhanVarsky/svg-object-extractor) |
| **diffvg** | Differentiable vector graphics rasterization (fork) | [IzhanVarsky/diffvg](https://github.com/IzhanVarsky/diffvg) |

# Vector Graphics Lab

Публичная витрина организации [VectorGraphicsLab](https://github.com/VectorGraphicsLab).

Мы занимаемся **векторной графикой и ML**: генеративный SVG, перенос стиля в векторной области и веб-инструменты вокруг этих моделей.
